# Family Card Verifier (পরিবার কার্ড আবেদনপত্র যাচাইকারী)

গণপ্রজাতন্ত্রী বাংলাদেশ সরকারের **সমাজসেবা অধিদফতরের (DSS)** পরিবার কার্ড আবেদনপত্র (PDF) থেকে স্বয়ংক্রিয়ভাবে বাংলা ও ইংরেজি তথ্য এক্সট্রাকশন, স্ট্রাকচার্ড JSON আউটপুট এবং ৫টি নির্ধারিত শর্তে ক্রস-ফিল্ড যাচাইকরণ করার **১০০% অফলাইন** Android অ্যাপ।

> এই অ্যাপটি সম্পূর্ণ ডিভাইসের ভেতরেই (On-device) কাজ করে — কোনো API Key, ক্লাউড সার্ভার বা ইন্টারনেট সংযোগের প্রয়োজন নেই।

## মূল সুবিধাসমূহ
- **২-স্তরের অফলাইন পিডিএফ পার্সার:**
  1. ডিজিটাল পিডিএফ থেকে সরাসরি এমবেডেড বাংলা টেক্সট স্ট্রিম (mPDF/Kalpurush PUA ও PDFBox) ডিকোড ও টেবিল এক্সট্রাকশন।
  2. স্ক্যানকৃত বা ছবির পিডিএফ হলে স্বয়ংক্রিয়ভাবে ২.৫x স্কেলে রেন্ডার করে বিল্ট-ইন **Tesseract (`ben+eng`)** অফলাইন OCR চালানো।
- **মাল্টি-পিডিএফ সিকোয়েন্সিয়াল কিউ:** একসাথে একাধিক পিডিএফ নির্বাচন করে ধারাবাহিকভাবে যাচাই ও ফিল্টারিং।
- **৫টি ক্রাইটেরিয়া যাচাই:** ওসিআর/JSON পূর্ণতা, বৈবাহিক অবস্থা (ব্যক্তিগত বনাম সদস্য ১), প্রবাসী সদস্য বনাম জীবিকার পেশা (`অন্যান্য`), টয়লেটের ধরন (`পিট/গর্ত` পরীক্ষা) এবং ৬টি নির্ধারিত পরিসম্পদ পরীক্ষা।

---

## লোকালি বিল্ড ও রান করার নিয়ম (Local Build Guide)

### পূর্বশর্ত (Prerequisites)
1. **[Android Studio](https://developer.android.com/studio)** (সর্বশেষ সংস্করণ, যার সাথে JDK 21 বান্ডেল থাকে)
2. Android SDK Manager থেকে **Android 16 (API 36.1)** SDK Platform ও Build-Tools ইন্সটল থাকতে হবে।

### পদ্ধতি ১: Android Studio ব্যবহার করে (সবচেয়ে সহজ)
1. Android Studio ওপেন করে **Open** বাটনে ক্লিক করুন এবং এই প্রজেক্ট ফোল্ডারটি (`d:\FC`) সিলেক্ট করুন।
2. Gradle Sync সম্পন্ন হওয়া পর্যন্ত অপেক্ষা করুন (প্রথমবার Gradle `9.3.1` ও ডিপেন্ডেন্সি ডাউনলোড হতে ইন্টারনেট লাগবে; বিল্ড হওয়ার পর অ্যাপ চালাতে ইন্টারনেট লাগবে না)।
3. এমুলেটর বা ফোনে সরাসরি চালাতে উপরের **Run (▶)** বাটনে ক্লিক করুন।
4. আলাদাভাবে ইন্সটলযোগ্য ডিবাগ APK তৈরি করতে মেনু থেকে **Build > Build Bundle(s) / APK(s) > Build APK(s)** সিলেক্ট করুন। তৈরি হওয়া APK পাওয়া যাবে:
   `app/build/outputs/apk/debug/app-debug.apk`

### পদ্ধতি ২: কমান্ড লাইন / টার্মিনাল ব্যবহার করে
যদি আপনার পিসিতে **JDK 17 বা JDK 21** (`JAVA_HOME`) এবং **Android SDK** (`ANDROID_HOME` অথবা `local.properties`-এ `sdk.dir=...`) সেট করা থাকে, তবে পাওয়ারশেল/টার্মিনালে চালান:

```powershell
# ডিবাগ APK তৈরি করতে:
.\gradlew.bat assembleDebug

# ইউনিট টেস্ট চালাতে:
.\gradlew.bat testDebugUnitTest
```
ডিবাগ APK তৈরি হবে `app\build\outputs\apk\debug\app-debug.apk` পাথে।

    private val preBaseVowels = setOf('ি', 'ে', 'ৈ')
    private val postBaseVowels = setOf('া', 'ী', 'ু', 'ূ', 'ৃ', 'ো', 'ৌ', 'ৗ', 'ঁ', 'ং', 'ঃ')

    private fun isBengaliConsonant(ch: Char): Boolean {
        val code = ch.code
        return (code in 0x0995..0x09B9) ||
            ch == 'ড়' || ch == 'ঢ়' || ch == 'য়' ||
            ch == 'ৎ' || ch == '\u09DC' || ch == '\u09DD' || ch == '\u09DF'
    }

    fun decodeVisualBengali(rawVisual: String): String {
        if (rawVisual.isEmpty()) return ""

        val expanded = StringBuilder(rawVisual.length + 16)
        for (ch in rawVisual) {
            val mapped = kalpurushPuaMap[ch.code]
            if (mapped != null) {
                expanded.append(mapped)
            } else {
                expanded.append(ch)
            }
        }

        val chars = expanded.toString().toMutableList()
        var i = 0
        while (i < chars.size) {
            val ch = chars[i]
            if (ch in preBaseVowels) {
                var j = i + 1
                if (j < chars.size && isBengaliConsonant(chars[j])) {
                    j++
                    while (j + 1 < chars.size && chars[j] == '্' && isBengaliConsonant(chars[j + 1])) {
                        j += 2
                    }
                    for (k in i until j - 1) {
                        chars[k] = chars[k + 1]
                    }
                    chars[j - 1] = ch
                    i = j
                    continue
                }
            }
            i++
        }

        var idx = 0
        while (idx < chars.size) {
            val code = chars[idx].code
            if (code == 0xE11E || code == 0xE11F) {
                var k = idx - 1
                while (k >= 0 && (chars[k] in preBaseVowels || chars[k] in postBaseVowels)) {
                    k--
                }
                if (k >= 0 && isBengaliConsonant(chars[k])) {
                    var startCluster = k
                    while (
                        startCluster - 2 >= 0 &&
                        chars[startCluster - 1] == '্' &&
                        isBengaliConsonant(chars[startCluster - 2])
                    ) {
                        startCluster -= 2
                    }
                    chars.removeAt(idx)
                    chars.add(startCluster, '্')
                    chars.add(startCluster, 'র')
                    idx++
                    continue
                } else {
                    chars[idx] = 'র'
                    chars.add(idx + 1, '্')
                    idx += 2
                    continue
                }
            }
            idx++
        }

        val logical = chars.joinToString("")
            .replace("ো", "ো")
            .replace("ৌ", "ৌ")
            .replace("ু্য", "্যু")
            .replace("ূ্য", "্যূ")
            .replace(Regex("\\s+"), " ")
            .trim()

        return Normalizer.normalize(logical, Normalizer.Form.NFC)
    }
}

        }

        if (directChars > 0) {
            val parsedDirect = OfflineFamilyCardExtractor.parseFromPositionedItems(directPositioned)
            if (hasMeaningfulFormFields(parsedDirect) || directChars >= 120) {

                    extractedData = parsedDirect,

                    usedOcrFallback = false,
                    extractedCharCount = directChars

        }

        val pdfBoxAttempt = tryExtractViaPdfBox(context, pdfBytes)

                return@withContext pdfBoxAttempt
            }
        }

            context = context,
            pdfBytes = pdfBytes,
            scale = PdfRendererHelper.OCR_RENDER_SCALE

            context = context,
            scaledPageBitmaps = scaledPageBitmaps,
            recycleBitmapsAfterUse = true,
            onPageProgress = onOcrPageProgress

            throw IllegalArgumentException(

                }
                stripper.sortByPosition = true
                val rawPlainText = BengaliPdfUnicodeDecoder.decodeVisualBengali(stripper.getText(document).orEmpty())
                val nonWsChars = positionedCollector.sumOf { item -> item.text.count { !it.isWhitespace() } }
                    .coerceAtLeast(rawPlainText.count { !it.isWhitespace() })

                if (nonWsChars == 0) {
                    return null
                }

                val coordParsed = OfflineFamilyCardExtractor.parseFromPositionedItems(positionedCollector)
                val finalData = if (hasMeaningfulFormFields(coordParsed)) {
                    coordParsed
                } else {
                    OcrFamilyCardParser.parseFromOcrText(rawPlainText)
                }

                PipelineExtractionOutcome(
                    extractedData = finalData,
                    engineUsedLabel = "ডিজিটাল পিডিএফ টেক্সট স্ট্রিম (PDFBox)",
                    usedOcrFallback = false,
                    extractedCharCount = nonWsChars
                )
            }
        } catch (_: Exception) {
            null
        }
    }

    private fun hasMeaningfulFormFields(data: ExtractedFamilyCardData): Boolean {
        return data.applicant.nameBangla.isNotBlank() ||
            data.applicant.nameEnglish.isNotBlank() ||
            data.applicant.nid.isNotBlank() ||
            data.familyMembers.isNotEmpty() ||
            data.householdInfo.toiletType.isNotBlank() ||
            data.householdInfo.ownedAssetsRaw.isNotBlank()
    }
