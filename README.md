# Family Card Verifier (পরিবার কার্ড আবেদনপত্র যাচাইকারী)

গণপ্রজাতন্ত্রী বাংলাদেশ সরকারের **সমাজসেবা অধিদফতরের (DSS)** পরিবার কার্ড আবেদনপত্র (PDF) থেকে স্বয়ংক্রিয়ভাবে বাংলা ও ইংরেজি তথ্য এক্সট্রাকশন, স্ট্রাকচার্ড JSON আউটপুট এবং নির্ধারিত ৬টি শর্তে ক্রস-ফিল্ড যাচাইকরণ করার **১০০% অফলাইন** Android অ্যাপ।

> এই অ্যাপটি সম্পূর্ণ ডিভাইসের ভেতরেই (On-device) কাজ করে — কোনো API Key, ক্লাউড সার্ভার বা ইন্টারনেট সংযোগের প্রয়োজন নেই।

## মূল সুবিধাসমূহ
- **২-স্তরের অফলাইন পিডিএফ পার্সার:**
  1. ডিজিটাল পিডিএফ থেকে সরাসরি এমবেডেড বাংলা টেক্সট স্ট্রিম (mPDF/Kalpurush PUA ও PDFBox) ডিকোড ও ২-কলাম/১-কলাম টেবিল এক্সট্রাকশন।
  2. স্ক্যানকৃত বা ছবির পিডিএফ হলে স্বয়ংক্রিয়ভাবে ২.৫x স্কেলে রেন্ডার করে বিল্ট-ইন **Tesseract (`ben+eng`)** অফলাইন OCR চালানো।
- **মাল্টি-পিডিএফ সিকোয়েন্সিয়াল কিউ:** একসাথে একাধিক পিডিএফ নির্বাচন করে ধারাবাহিকভাবে যাচাই ও ফিল্টারিং।
- **৬টি ক্রাইটেরিয়া যাচাই:**
  1. টেক্সট/OCR এক্সট্রাকশন ও JSON পূর্ণতা যাচাই
  2. বৈবাহিক অবস্থা যাচাই (ব্যক্তিগত তথ্য বনাম পরিবারের সদস্য ১)
  3. প্রবাসী সদস্য বনাম জীবিকার পেশা (`অন্যান্য`) যাচাই
  4. খানায় মোট জমির পরিমাণ যাচাই (`খানার সকল সদস্যের মালিকানাধীন মোট জমির পরিমাণ কত?` — যদি `কোন জমি নেই` উল্লেখ থাকে তবে অসঙ্গতির সতর্কবার্তা প্রদান)
  5. পায়খানা/টয়লেটের ধরন (`পিট/গর্ত` পরীক্ষা)
  6. নির্ধারিত পরিসম্পদ পরীক্ষা (`খানার মালিকানাধীন নিম্নের পরিসম্পদ গুলোর কোনটি আছে ?`)
